# Сессии RC Transmitter

Открывай корень репозитория в Codex как один проект. Для каждой самостоятельной задачи создавай отдельную сессию в этом проекте. Указывай название задачи, её цель и путь к записи. Для продолжения задачи открывай её прежнюю сессию или передавай путь к записи в новую.

| Название сессии | Стартовая задача |
|---|---|
| **Тримы — ETHOS и SCR_TRIMS** | Прочитай `docs/sessions/trims.md`. Проверь текущие тримы в коде и продолжи со следующего шага в записи. |
| **EEZ — экраны и виджеты** | Открой проект в `eez_project/`. Найди нужный экран и его обработчики. Веди запись текущей задачи в `docs/sessions/eez.md` с момента её начала. |
| **Микшеры и режимы полёта** | Начни с `lib/Mixer/`, `lib/FlightModeManager/` и `lib/ModelRuntime/`. Веди запись текущей задачи в `docs/sessions/mixer.md` с момента её начала. |
| **Аппаратная часть — входы и калибровка** | Начни с `docs/`, `lib/InputManager/` и `lib/calibration/`. Веди запись текущей задачи в `docs/sessions/hardware.md` с момента её начала. |

Для одновременной правки общих файлов используй отдельные Git-ветки и рабочие деревья. Перед объединением изменений проверь пересечения в обработчиках UI и модели.

Запись задачи содержит цель, ветку или коммит, подтверждённые наблюдения и решения, затронутые файлы, выполненные проверки и ближайший следующий шаг.
