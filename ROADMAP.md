# RC Transmitter — Roadmap

Основание: отчёт локального снимка разработки от 2026-11-23. Это **план**, а не подтверждение выполнения в GitHub main.

## P0 — синхронизация и безопасность данных
- [ ] **SYNC-EEZ:** получить последнюю локальную версию `.eez-project` и сгенерированные `screens.c/.h`; проверить три категории внутри `trims_category_list_panel`; не использовать устаревший EEZ-проект для генерации.
- [ ] **STAGE13-HW:** синхронизировать полный локальный Stage 13, выполнить PlatformIO-сборку, сделать резервную копию SD; проверить save/load/restart и восстановление `.bak` на копии SD.

## P1 — тесты и регрессия
- [ ] **TEST-HEADER:** исправить только устаревшее ожидание `TestStage1241.test_trims_header`, не менять рабочий UI.
- [ ] **STAGE14:** провести регрессию FreeMix, Aileron, Curve Clone, Vars/Trims, Switches Normal/Reverse, Balance, переключения моделей и SD; сохранить протокол аппаратных тестов.
- [ ] **SD-UI:** реализовать достоверные статусы «в очереди / записано / ошибка» после согласования UI.
- [ ] **MCP-FAULT:** определить и проверить безопасное поведение при ошибке чтения MCP23017, включая `SW?` и диагностику Serial.

## P2 — функциональное развитие
- [ ] Реализовать Variables Active Condition Direction.
- [ ] Проработать Gyro switches как реальную категорию условий.
- [ ] Подключить и проверить незавершённые System Events.
- [ ] Разделить на самостоятельные задачи Model Wizard, версию модели/миграции, перенос `aileronMix` и `varsorder`, энкодер Curve Selector.
- [ ] Составить матрицу испытаний RF, телеметрии, тренера и типов миксов.

## Управление проектом и сайт
- [ ] **RC-001:** организация задач, AI-инструкций, архитектуры, журнала изменений и веб-портала.
- [ ] Спроектировать публикацию статусов на InfinityFree с GitHub как источником истины; не помещать токены доступа в публичный сайт.

## Правила закрытия
Задача закрывается только после фиксации изменённых файлов, результатов тестов, аппаратного подтверждения там, где оно необходимо, и оставшихся рисков. Не считать наличие исходников эквивалентом проверенной функции.
