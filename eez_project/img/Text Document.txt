Ниже дам уже не общее описание, а нормальную принципиальную архитектуру работы всей системы — от движения стика до выхода PWM на приёмнике и возврата телеметрии на пульт.

Принципиальная работа системы

Система представляет собой двунаправленный радиокомплекс управления моделью, состоящий из двух основных устройств:

Пульт передатчика (TX) — считывает органы управления, обрабатывает их, выполняет микширование и формирует управляющие пакеты.
Приёмник (RX) — принимает пакеты, проверяет их, формирует выходные сигналы для модели и одновременно собирает телеметрию.

Радиосвязь между ними осуществляется через E22-900N30S в диапазоне 900 МГц. Обмен является двунаправленным: пульт постоянно передаёт команды, а приёмник возвращает телеметрию.

1. Пульт передатчика

Основой пульта является ESP32-P4-WiFi6 с сенсорным дисплеем 4,3" 480×800.

ESP32-P4 выполняет сразу несколько задач:

считывает органы управления;
получает данные от ADS1115;
фильтрует и нормализует аналоговые значения;
применяет к ним калибровку;
выполняет trim;
применяет curves/expo;
выполняет микширование;
рассчитывает логические функции;
формирует радиопакеты;
передаёт их через E22;
принимает телеметрию;
обновляет интерфейс LVGL;
записывает настройки и логи.

То есть дисплей здесь не является отдельным вычислительным устройством. Основная логика системы находится в ESP32-P4, а дисплей является интерфейсом пользователя.

Таким образом, с одного физического стика можно получить несколько независимых управляющих параметров.

Они особенно удобны для параметров, которые должны возвращаться в центральное положение после отпускания.

3. Считывание аналоговых органов управления

Аналоговые сигналы поступают на ADS1115.

В проекте используется несколько ADS1115, чтобы получить достаточное количество аналоговых каналов.

ADS1115 имеет разрешение 16 бит, поэтому программное обеспечение получает значительно более точное значение положения органа управления, чем при использовании простого 10-битного ADC.

Путь данных выглядит так:

Стик → аналоговое напряжение → ADS1115 → I²C → ESP32-P4

Например:

Стик AIL
   ↓
ADS1115
   ↓
значение ADC
   ↓
фильтрация
   ↓
калибровка
   ↓
-100 ... +100 %
4. Калибровка

После включения или через меню Calibration пользователь может откалибровать органы управления.

Для каждого канала система запоминает:

минимальное положение;
центральное положение;
максимальное положение;
направление;
величину центрального отклонения.

Например, реальный ADC может выдавать:

MIN     CENTER      MAX
850       2047      3270

Программное обеспечение преобразует это в:

-100%       0%       +100%

Поэтому физические различия между стиками и потенциометрами не влияют на последующую обработку.

5. Фильтрация

До применения микширования значение проходит фильтрацию.

Это необходимо потому, что аналоговый сигнал никогда не является абсолютно стабильным.

Например, физически неподвижный стик может давать:

2046
2048
2047
2050
2045
2049

Для пользователя это всё центральное положение.

Фильтр превращает эти небольшие колебания в стабильное значение.

При этом фильтр должен быть достаточно быстрым, чтобы не создавать заметную задержку управления.

6. Нормализация

После фильтрации значение переводится во внутренний формат системы.

Например:

MIN      CENTER      MAX
-100%       0%       +100%

После получения Input система может применить кривую.

9. Mixer

Mixer — один из центральных элементов всей системы.

Он преобразует Inputs в реальные выходные каналы.

Например:

AIL → CH1
ELE → CH2
THR → CH3
RUD → CH4

Но mixer позволяет делать и более сложные операции.

Например:

AIL → CH1   +100%
AIL → CH2   -100%

Получается управление двумя сервоприводами от одного стика.

Другой пример:

ELE → CH2  +100%
ELE → CH6   +20%

Теперь elevator одновременно влияет на основной канал и дополнительный канал.

10. Weight

Weight определяет степень влияния источника.

Например:

Weight = 100%

означает полный диапазон.

Weight = 50%

уменьшает влияние в два раза.

Например:

AIL = +80%
Weight = 50%

результат:

+40%
11. Offset

Offset добавляет постоянное смещение.

Например:

Input = 0%
Offset = +10%

результат:

+10%

Это используется для:

установки нейтрали;
механической компенсации;
специальных микшеров;
настройки положения исполнительного механизма.
12. Trim

Trim позволяет изменять центральное положение управляющего канала, не меняя основной диапазон стика.

Например:

AIL = 0%
Trim = +3%

система получает небольшую постоянную поправку.

Trim особенно полезен при настройке модели в полёте.

13. Output

После всех преобразований получается конечное значение канала.

Например:

CH1 AILERON    +12%
CH2 ELEVATOR    -7%
CH3 THROTTLE   +65%
CH4 RUDDER      -3%
CH5 GEAR       +100%
CH6 FLAPS       +50%

Далее эти значения переводятся в физический формат управляющего сигнала.

Например для PWM:

-100% → 1000 µs
   0% → 1500 µs
+100% → 2000 µs

Конкретные MIN/MAX могут быть настроены пользователем.

16. CRC

В конец пакета помещается контрольная сумма.

Условно:

DATA
 ↓
CRC calculation
 ↓
CRC = 0xA37F

Приёмник самостоятельно рассчитывает CRC полученного пакета.

Если:

CRC received == CRC calculated

пакет считается корректным.

Если:

CRC received != CRC calculated

пакет отбрасывается.

Это защищает систему от использования повреждённых данных.

20. Failsafe

Это один из важнейших элементов системы.

Приёмник постоянно отслеживает время последнего корректного пакета.

Например:

Последний пакет:
T = 1000 ms


Текущий момент:
T = 1005 ms

Связь ещё считается нормальной.

При отсутствии корректных пакетов время продолжает увеличиваться.

После достижения заданного тайм-аута активируется Failsafe.

Например:

100 ms → предупреждение
200 ms → Failsafe

Само значение должно задаваться параметрами протокола.

21. Режимы Failsafe

Для каждого канала можно задать собственное поведение.

Например:

CH1 AIL      HOLD
CH2 ELE      HOLD
CH3 THR      1000 µs
CH4 RUD      HOLD
CH5 GEAR     2000 µs
CH6 FLAPS    1500 µs

Поэтому Failsafe не обязательно означает одно действие для всех каналов.

27. Что происходит за один цикл

Практически один цикл можно представить так:

1. ESP32-P4 считывает положение стиков.

2. ADS1115 возвращает значения ADC.

3. Программа фильтрует их.

4. Применяется калибровка.

5. Значения переводятся в диапазон -100…+100%.

6. Применяются Trim, Weight, Offset и Curves.

7. Mixer рассчитывает конечные каналы.

8. Проверяются Logical Switches.

9. Выполняются Special Functions.

10. Формируются конечные значения CH1…CHn.

11. Создаётся радиопакет.

12. Пакет отправляется через E22.

13. Приёмник принимает его.

14. Проверяется CRC и последовательность.

15. Приёмник обновляет выходы.

16. Параллельно считываются датчики.

17. Формируется телеметрический пакет.

18. Телеметрия возвращается на пульт.

19. ESP32-P4 обновляет значения на экране.

И этот процесс повторяется постоянно.
