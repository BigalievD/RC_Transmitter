# RC Transmitter

Прошивка RC-передатчика на ESP32-P4/Waveshare с интерфейсом EEZ Studio и LVGL.

## Где работать

| Папка или файл | Содержание |
|---|---|
| `src/` | Точка входа прошивки, обработчики UI и переменные для связи с EEZ. |
| `src/ui/` | UI-код, используемый прошивкой. |
| `eez_project/` | Проект `Transmitter+Display.eez-project`, шрифты, изображения и копия UI-кода в `src/ui/` внутри папки проекта EEZ. |
| `lib/` | Модули прошивки, включая тримы, микшеры, режимы полёта, входы и выходы. |
| `lib/Model/`, `lib/ModelRuntime/` | Конфигурация, хранение и выполнение модели. |
| `include/`, `platformio.ini`, `partitions.csv` | Общие заголовки, параметры сборки и разметка памяти. |
| `docs/` | Схемы, распиновка и заметки об оборудовании. |
| [docs/sessions/](docs/sessions/README.md) | Состояние задач и команды для начала отдельных сессий. |
| [AGENTS.md](AGENTS.md) | Постоянные правила для Codex. |

## Сборка

Из корня проекта с установленным PlatformIO:

```sh
pio run -e Waveshare
```
