# RC Transmitter

Прошивка RC-передатчика для ESP32-P4/Waveshare. Интерфейс моделей проектируется с опорой на FrSky ETHOS. В репозитории используется PlatformIO, Arduino, EEZ Studio и LVGL.

## Начало работы

- Определи цель сессии, проверь ветку и состояние рабочего дерева. Прочитай карту проекта в [README.md](README.md) и запись нужной задачи в [docs/sessions/](docs/sessions/README.md).
- Веди короткий план действий и обновляй его по результатам проверки. Для новой функции укажи, какое поведение должно быть видно в интерфейсе или на выходах передатчика.
- Для совместимости с ETHOS указывай версию прошивки или симулятора. Фиксируй отдельно наблюдение, сведения из документации и предположение. Для технических утверждений, требующих проверки, приводи ссылки на документацию, релизы или профильные обсуждения.

## Правила C++

- Однострочное действие внутри `if` оформляй на одной строке без фигурных скобок. Для нескольких действий используй блок.
- Объявление или заголовок определения функции вместе со списком параметров располагай на одной строке.

```cpp
if (value == previousValue) return;
void process(const int16_t inputs[MAX_MIX_CHANNELS], int16_t outputs[MAX_MIX_CHANNELS]);
```

## Работа с проектом

- Для изменений макета найди исходный экран в проекте EEZ. Сверь конфигурацию экспорта и копии UI-кода перед регенерацией. Связь интерфейса с прошивкой проверяй в `src/actions.cpp` и `src/vars.cpp`.
- Для изменений модели проследи путь от редактирования через конфигурацию и сохранение до расчёта в рабочем цикле. Проверяй чтение ранее сохранённых моделей при изменении формата.
- Сохраняй пользовательские изменения в рабочем дереве. Правки ограничивай задачей сессии.

## Проверка и передача работы

- Проверяй изменения через штатную точку входа функции. Для прошивки команда сборки из корня — `pio run -e Waveshare`. В отчёте укажи фактически выполненные проверки, их результат и проверки на устройстве, которые ещё предстоят.
- В конце сессии обнови её запись при появлении новых решений, результатов или препятствий. Укажи ветку или коммит, изменённые файлы и один конкретный следующий шаг.
